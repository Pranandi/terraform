# Multi-Environment Azure Cloud & Infrastructure Hub 🚀

Welcome to my central infrastructure-as-code repository. This project demonstrates enterprise-ready cloud designs using Terraform, modular architectures, and structured CI/CD workflows.

## 🏗️ Repository Architecture & Directories
*   **`AZvm/`**: Automated virtual machine infrastructure provisioning using standard scaling paradigms.
*   **`Functionaz/`**: Serverless Azure Function App stacks managed natively as code.
*   **`azurepolicy/`**: Infrastructure governance templates mapping directly to enterprise compliance requirements.

## 🛠️ Tech Stack & Tooling
*   **Cloud Provider:** Microsoft Azure
*   **Infrastructure as Code:** Terraform
*   **CI/CD Pipeline:** GitHub Actions (Automated checking via `terraform fmt` and `terraform validate`)

## 🚀 How to Run Locally
1. Initialize the directory to pull modules: `terraform init`
2. Check changes against active state: `terraform plan`
3. Safely provision architecture: `terraform apply`
